# 🌟 student_management_system🌟

Welcome! I'm excited to share my academic project: a **CRUD-based Exam Management System** built as part of my journey as an ICT engineering student. This web application demonstrates my ability to integrate backend and frontend technologies to deliver a functional, user-friendly system.

---

## 🛠️ Technologies Used

- **IDE:** Eclipse  
- **Server:** WildFly  
- **Backend:** Java Servlets, JPA (Hibernate)  
- **Database:** MySQL  
- **Frontend:** JSP, HTML, CSS, Bootstrap, JavaScript  

---

## 📌 Project Overview

This system allows users to:

- **Manage Exams:** Create, update, delete, and view exam records.  
- **Handle Student Profiles:** Perform CRUD operations for student data.  
- **Schedule Sessions:** Associate exams with specific time slots.  
- **Enjoy a Seamless Experience:** Features a responsive and interactive UI.

The project showcases full-stack integration, ensuring smooth communication between frontend and backend layers.

---

## ✨ How It Works

### 🎨 Frontend Design

- Dynamic pages created using **JSP**, styled with **Bootstrap** and enhanced with **JavaScript**.
- Responsive layouts for a consistent experience across devices.

### 🧠 Backend Logic

- **Java Servlets** handle routing, logic, and user input processing.
- **JPA (Hibernate)** manages database operations, translating Java entities into MySQL records.

### 🗄️ Database

- A relational structure connecting exams, students, and sessions.
- **MySQL** used as the database engine.

### 🚀 Deployment

- Deployed locally using **WildFly** for testing and demonstration.
